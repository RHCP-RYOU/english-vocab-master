English Vocabulary MASTER - PC / iPhone 共通版

GitHub Pages 用ファイルです。

構成:
- index.html : 画面
- styles.css : 共通デザイン
- app.js : 学習ロジック
- words.js : 語彙マスター（現在500語。将来追加可能）
- .nojekyll : GitHub Pages 用

重要:
1. 4択では回答前に正解の日本語訳を別領域へ表示しません。
2. IPAを発音の基準とし、カタカナは補助的な発音ガイドです。
3. 総語数はコードに固定していません。words.jsへ語彙を追加すれば自動反映されます。
4. PCとiPhoneは同じURL・同じ語彙データ・同じ学習ロジックを使用します。
5. 学習履歴は端末/ブラウザごとのlocalStorageに保存されます。必要ならJSONで書き出し/読み込みできます。
